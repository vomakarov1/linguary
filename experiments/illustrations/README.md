# Оценка канала подготовки иллюстраций (`P5.T1`)

Скрипт `experiments/illustrations/evaluate.py` воспроизводимо проверяет инварианты,
ограничения по размеру запросов и числу вызовов, а также защиту от враждебных ответов модели.

## Запуск в детерминированном fake-режиме (без сети и расходов)

```sh
uv run python experiments/illustrations/evaluate.py \
  --fixtures tests/fixtures/illustrations/synthetic_cases.json \
  --mode fake \
  --output ./eval-out
```

Артефакты (`report.json` и `summary.md`) содержат:
- контрольные суммы `source_sha256`, `manifest_sha256`, `registry_sha256`;
- измеренные ограничения (`max_input_bytes_observed`, `calls_sent`, число областей);
- результаты проверки враждебных сценариев (чужой `block_id`, битая цитата, будущий спойлер, дубликат сцены, ID-only промт);
- редакционную рубрику для отдельной живой оценки.

## Платный live-режим

Режим `--mode live` требует явного флага `--allow-paid-calls` и настроенного провайдера LLM.
Без `--allow-paid-calls` скрипт завершает работу с ненулевым кодом до создания HTTP-клиента.

> **Важно:** прогон в `fake`-режиме доказывает механику, границы и сохранность данных,
> но не редакционное качество реальной модели. Живая оценка выполняется отдельно после
> согласования контрольных глав (ADR §9).
