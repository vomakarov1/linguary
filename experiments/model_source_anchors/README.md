# Сравнение способов привязки цитат

Изолированный опыт для BRIEF `BRIEF-model-source-anchors-2026-11-07`. Он не импортируется приложением и не меняет его рабочие запросы.

## Набор данных

Используется рассказ Charlotte Perkins Gilman *The Yellow Wallpaper*, Project Gutenberg, eBook №1952: [страница книги](https://www.gutenberg.org/ebooks/1952), [исходный текст](https://www.gutenberg.org/cache/epub/1952/pg1952.txt). Зафиксированная версия исходного файла имеет SHA-256 `20c7788eeae2fe3a0efd51a1f08b6723366a4be0778d65db219149a3522651d4`. Условия Project Gutenberg доступны на [странице лицензии](https://www.gutenberg.org/policy/license.html).

В наборе 10 фрагментов, один блок `b1` на случай и одна ожидаемая опора на фрагмент. При подготовке свёрнуты только переносы строк внутри абзацев; границы абзацев сохранены. Для каждого блока записан SHA-256 точного текста, который попадёт в запрос. `expected_fact` и контрольные цитаты остаются в снимке для оценщика и не добавляются в запрос модели.

Если Project Gutenberg заменит текст, `prepare_cases.py` остановится на несовпадении SHA-256. Не обновляйте ожидаемый хеш без повторной проверки источника и набора отрывков.

## Запуск

Нужен ключ OpenRouter в переменной окружения `OPENROUTER_API_KEY`. Скрипт не читает ключ из файлов и не записывает его в результаты.

```sh
python3 experiments/model_source_anchors/prepare_cases.py
python3 experiments/model_source_anchors/run.py run --execute
```

Before the second command, set `OPENROUTER_API_KEY` securely in the shell environment.

Запуск создаёт ровно 40 запросов модели: 10 фрагментов × 2 схемы × 2 независимых повтора. Запросы выполняются по одному, без истории и автоматических повторов; порядок схем внутри каждой пары перемешан фиксированным начальным значением. Используется модель [`deepseek/deepseek-v3.2`](https://openrouter.ai/deepseek/deepseek-v3.2), `temperature=0.2`, `top_p=1.0`, `max_tokens=512` и строгая JSON Schema. Сведения о фактическом провайдере, расходе токенов и стоимости запрашиваются отдельно по идентификатору генерации и не считаются дополнительными вызовами модели.

`--execute` обязателен, чтобы случайно не отправить платные запросы. Ключ и заголовки авторизации не сохраняются. Точные запросы без ключа, сырые ответы, время, сведения о генерации и отчёт сохраняются в `.ai/develop-context.local/BRIEF-model-source-anchors-2026-11-07/runs/`.

## Ручная оценка и отчёт

В `evaluation.csv` заполните для каждого ответа:

- `manual_fact_supported`: подтверждает ли ответ ожидаемый факт (`yes`, `no` или `uncertain`);
- `manual_quote_supports_aid`: подтверждает ли цитата пояснение модели (`yes`, `no` или `uncertain`);
- `manual_reason`: краткое обоснование.

После оценки обновите отчёт:

```sh
python3 experiments/model_source_anchors/run.py report .ai/develop-context.local/BRIEF-model-source-anchors-2026-11-07/runs/<run-id>
```

Для схемы с координатами позиция правильна, если `text[start:end]` точно равен цитате. Для схемы только с цитатой привязка разрешима при ровно одном точном вхождении в тот же блок. Отсутствующие ответы остаются в знаменателях; альтернативная дословная цитата может получить ручную оценку `yes`, если она подтверждает тот же факт. Выводы относятся только к этой книге и десяти фрагментам.
